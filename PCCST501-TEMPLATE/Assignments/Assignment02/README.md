# Assignment 3

## Title

Data-Link Layer, Ethernet and Wireless LANs

## Objective

To study the functions of the Data-Link Layer, Ethernet, MAC addressing, switching, CSMA/CD, CSMA/CA, WLAN design, and Mobile IP.

## Solution

The Data-Link Layer provides framing, MAC addressing, error detection, flow control, and medium access control. The assignment also covers Ethernet frames, MAC address learning in switches, CSMA/CD and CSMA/CA, WLAN design, Mobile IP, and IEEE 802.11 frames.

## Output

The assignment demonstrates how data is transferred through Ethernet and wireless networks using frames, MAC addresses, switches, and access control methods. It also compares Ethernet and 802.11 frames and presents a WLAN design for a laboratory.

## Conclusion

The Data-Link Layer enables reliable local network communication through framing, addressing, error detection, and access control, while Ethernet and wireless LAN technologies provide efficient network connectivity.
